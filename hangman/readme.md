# Hangman Game

## Description
Hangman is a simple word-guessing game developed in Python. The player tries to guess a hidden word one letter at a time. Each incorrect guess reduces the number of remaining attempts. The game ends when the player guesses the word correctly or runs out of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Tracks correct and incorrect guesses
- Limited number of attempts
- Win and lose messages
- Beginner-friendly Python project

## Requirements
- Python 3.x

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Run the following command:

```bash
python hangman.py
```
