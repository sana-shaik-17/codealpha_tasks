### **TASK 2: Stock Portfolio Tracker**

**Goal:**
Build a simple stock tracker that calculates the total investment based on manually defined stock prices.

### **Simplified Scope**

* The user enters **stock names** and **quantity**.
* Use a **hardcoded dictionary** to store stock prices.

  * Example:

    ```python
    {
        "AAPL": 180,
        "TSLA": 250
    }
    ```
* Calculate the **total investment value**.
* Display the result.
* **Optionally**, save the result in a **.txt** or **.csv** file.

### **Key Concepts Used**

* Dictionary
* Input/Output
* Basic Arithmetic
* File Handling (Optional)

### **What you need to do**

1. Create a dictionary containing stock names and their prices.
2. Ask the user how many different stocks they own.
3. For each stock:

   * Enter the stock name.
   * Enter the quantity.
4. Multiply the stock price by the quantity.
5. Add all investment values together.
6. Print the total investment.
7. (Optional) Save the result to a text or CSV file.

This is a **beginner-level project** designed to help you practice dictionaries, loops, user input, calculations, and basic file handling in Python. It does **not** require live stock prices or internet access.
