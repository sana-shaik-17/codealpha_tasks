
# Basic Chatbot

## Description
This is a simple rule-based chatbot built using Python. It responds to basic user inputs such as greetings and simple questions using predefined answers.

## Features
- Greets the user
- Answers simple questions
- Responds to unknown inputs
- Exits when the user types "bye"

## Technologies Used
- Python 3

## How to Run
1. Open the project in VS Code or any Python IDE.
2. Run the `chatbot.py` file.
3. Start chatting with the bot.
4. Type `bye` to exit.

- `chatbot.py` – Main Python program
